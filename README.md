# 📊 Mobile Sales Dashboard | Power BI

An interactive Power BI dashboard built to analyze mobile phone sales across different cities, brands, payment methods, and time periods.

---

# Project Overview

This dashboard provides insights into:

- Total Sales
- Total Quantity Sold
- Number of Transactions
- Average Sales
- Monthly Sales Trends
- Sales by City
- Top Selling Models
- Top Brands
- Customer Ratings
- Payment Method Distribution
- Sales by Day of Week

The dashboard is fully interactive using slicers and cross-filtering.
